# Chordscape

和音を押して、響きと構成音を探索する静的アプリ。
An interactive playground for learning chords, progressions, voicings, and modulation through sound and visualization.

「和声空間」では42個の和音を空間上で試聴できます。12 major keys、Free / Pop / Jazz / Classicalの候補提示、灰色の履歴表示、自動voice leadingに対応。演奏進行への記録・保存は行いません。

[Chordscapeを開く](https://d1ssk.github.io/chordscape/)

## できること

- 長調15調・自然短調15調（異名同音を含む）、三和音／七の和音。F majorのB♭、F♯ majorのE♯など調に沿って綴ります。
- 調外パレット：指定順の長調27ボタン／自然短調27ボタン（短調のF7相当は2か所に表示）。他の調へは根音の度数・綴りを保って移調します。カテゴリ見出しとD♭/F相当のプリセットは置きません。分析は候補・変化音・解決先を示し、実際に続く和音との関係も説明します。
- 調外パレットの「＋ 追加」から、根音と33種類のコードを選んで自分の和音を登録・削除できます。追加分はリロード後もこのブラウザに残り、調を変えてもコード名を保持します。進行のJSONには含まれません。
- 即時試聴、記録オン／オフ、進行の選択・複製・削除・drag／移動ボタン・長さ変更・全消去、Undo/Redo（直近50編集）。
- Play / Pause / Resume / Stop、40–200 BPM、ループ、拍位置・発音中／次の和音。**Piano**（初期設定）、**Electric piano**、**Pad**、**Soft synth**の4音色。
- 構成音bassの手動指定、slash表示と転回数字、実音MIDI鍵盤、根音／bassの別表示。手動（配置を保持） / Root position / Smoothと同じ進行でのA/B試聴。全転回形でオクターブ上下に対応。
- 33種類のコード辞典。根音を選ぶと33種類のコードがボタンで並び、押すと選択・試聴できます。構成音・音程・現れる調を確認でき、「進行へ追加」は別操作です。
- 辞典はBasic → Seventh → Added tones / Sixth → Extensions → Alteredの学習順に分類。小さな見出しと6列のボタンで表示し、根音を変えても順序を保ちます。
- 7♭5、m(M7)、7sus4、7♯5、M7♯5、6/9、m(add9)、7♭9、7♯9、M7(♯11)、11、m11、13、m13、M13、7(♭9,♯5)に対応。11系・13系は省略なしの6音・7音で、第5・第6転回も選べます。聞き流しの名前音声は録音済みの既存17種類が対象です。
- ブラウザへの自動保存、schemaVersion付きJSONの書出し／検証付き読込、全体移調。日本語／英語、desktop／mobile、キーボード操作。
- 下部ナビゲーションで「ホーム」「生成」「五度圏」「コード辞典」「和声空間」を切り替えます。設定は右上。全画面でChordscapeとロゴ、ホーム以外は隣にページ名を表示し、PCの最大幅を統一しています。ブラウザの戻る操作にも対応。ダイアトニックコードは三和音と七の和音の2行で表示し、モバイルでも各行7個の横並びを保ちます。五度圏の三和音／七の和音の比較設定は五度圏画面内で選べます。
- Pop / Jazzの進行生成、seedの指定・保存、フレーズごとの連続生成。生成後の編集、再生成のUndo/Redo、生成意図と実際の前後関係の解説。
- 五度圏での比較・転調ブリッジ・連続巡回。発音と同期した調の切替と旧新の分析。
- コード辞典から4モードの聞き流し。日本語の名前とPianoを20分の音声にまとめ、反復再生・ロック画面操作・WAV保存。
- Timeline / Liveの旋律生成、ピアノロール、伴奏と分けた鍵盤表示、旋律の音域・密度・動き・音量・モチーフ・Seedの設定。

### 最初の操作

1. C、G、Am、Fをそのまま押します。最初の操作で音声と音源を準備し、選んだコードが鳴ります。「音声を開始」の事前操作は不要です。初期は記録オン、1イベント4拍、90 BPMです。
2. 「再生」で進行を聴きます。「停止」は予約とvoiceを止めて先頭へ戻します。「一時停止」→「再開」は保持した拍から再発音します。
3. 停止中にイベントを選び、転回を変更します。常に表示する「選択イベントの編集」で長さ・転回・オクターブを調整できます。テンポ・拍数・記録・ループ、配置・A/B試聴・全体移調は進行パネルに常時表示しています。
4. 「コード辞典」で和音を選んで試聴できます。「進行へ追加」でホームに戻ります。
5. 「設定」で音色・音量・言語を選び、JSONの書出し／読込を行います。画面右上の音色名からも設定を開けます。
6. 「生成」の「コードの生成」でPop / Jazzを選び「生成する」を押すと、編集可能な進行に置き換わります。生成そのものは音声開始前でも利用できます。

再生中はパレットが無効です。ループ編集は次の未予約の周回へ反映され、現在の周回は変えません。一時停止中に進行自体を編集した場合は停止状態に戻り、編集済み進行を先頭から再生します。テンポ変更は拍を保って短く再発音します。タブ非表示やAudioContext中断時は一時停止し、復帰後にユーザーが再開します。

調選択は次の和音の文脈を変え、既存の音高とイベントの調は保持します。「進行全体を移調」は全イベントと各調を同じ半音差で移します。

## 制約

聞き流しのquiz、英語音声・声の切替、画面オフ中の無限新規生成、旋律の五線譜表示は未実装です。追加style（Classical-ish / City Pop / Lo-fi / Film）、tritone substitution、和音の省略・重複、非構成音bass、独立bassパート、通常の進行／旋律の音声書出し、オフライン起動・ホーム画面へのインストール機能も提供していません。
