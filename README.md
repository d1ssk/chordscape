# Chordscape

和音を押して、響きと構成音を探索する静的アプリ。
An interactive playground for learning chords, progressions, voicings, and modulation through sound and visualization.

「和声空間」では42個の和音を空間上で試聴できます。12 major keys、Free / Pop / Jazz / Classicalの候補提示、灰色の履歴表示、自動voice leadingに対応。演奏進行への記録・保存は行いません。詳細は [Harmonic Space](docs/HARMONIC_SPACE.md) を参照してください。

## 開発

Node **22 LTS (22.13以上、23未満)** と npm を使用。`.nvmrc`、engines、CIを22系に統一しています。

```sh
nvm use
npm ci
npx playwright install chromium
npm run dev
```

## Pages

`ci.yml` はPRとmainでcheckとroot / subpathのE2Eを実行。`pages.yml` はmainだけでcheck・E2Eを通した同じ `dist` を公開します。PATは不要です。

Settings → Pages → Source は **GitHub Actions** に設定済みです。別のリポジトリで使う場合も同じ設定にしてください。公開範囲は変更しません。

baseは `GITHUB_REPOSITORY` から導出します。`<owner>/<owner>.github.io` または `public/CNAME` があれば `/`。custom domainなどでは repository variable **PAGES_BASE_PATH** に `/` 等を設定して上書きできます。ローカルは `/`、手動指定は `VITE_BASE_PATH`。assetはVite経由で解決し、history routerは使用しません。

## P1–P5でできること

- 長調15調・自然短調15調（異名同音を含む）、三和音／七の和音。F majorのB♭、F♯ majorのE♯など調に沿って綴ります。
- 調外パレット：指定順の長調27ボタン／自然短調27ボタン（短調のF7相当は2か所に表示）。他の調へは根音の度数・綴りを保って移調します。カテゴリ見出しとD♭/F相当のプリセットは置きません。分析は候補・変化音・解決先を示し、実際に続く和音との関係も説明します。
- 調外パレットの「＋ 追加」から、根音と33種類のコードを選んで自分の和音を登録・削除できます。追加分はリロード後もこのブラウザに残り、調を変えてもコード名を保持します。進行のJSONには含まれません。
- 即時試聴、記録オン／オフ、進行の選択・複製・削除・drag／移動ボタン・長さ変更・全消去、Undo/Redo（直近50編集）。
- Play / Pause / Resume / Stop、40–200 BPM、ループ、拍位置・発音中／次の和音。**Piano**（初期設定）、**Electric piano**、**Pad**、**Soft synth**の4音色。
- 構成音bassの手動指定、slash表示と転回数字、実音MIDI鍵盤、根音／bassの別表示。手動（配置を保持） / Root position / Smoothと同じ進行でのA/B試聴。全転回形でオクターブ上下に対応。
- 33種類のコード辞典。根音を選ぶと33種類のコードがボタンで並び、押すと選択・試聴できます。構成音・音程・現れる調を確認でき、「進行へ追加」は別操作です。
- 辞典はBasic → Seventh → Added tones / Sixth → Extensions → Alteredの学習順に分類。小さな見出しと6列のボタンで表示し、根音を変えても順序を保ちます。
- 7♭5、m(M7)、7sus4、7♯5、M7♯5、6/9、m(add9)、7♭9、7♯9、M7(♯11)、11、m11、13、m13、M13、7(♭9,♯5)に対応。11系・13系は省略なしの6音・7音で、第5・第6転回も選べます。聞き流しの名前音声は録音済みの既存17種類が対象です。
- ブラウザへの自動保存、schemaVersion付きJSONの書出し／検証付き読込、全体移調。日本語／英語、desktop／mobile、キーボード操作。
- 下部ナビゲーションで「ホーム」「生成」「五度圏」「コード辞典」「和声空間」を切り替えます。設定は右上。全画面でChordscapeとロゴ、ホーム以外は隣にページ名を表示し、PCの最大幅を統一しています。ブラウザの戻る操作にも対応。ダイアトニックコードは三和音と七の和音の2行で表示し、モバイルでも各行7個の横並びを保ちます。五度圏の三和音／七の和音の比較設定は五度圏画面内で選べます。
- Pop / Jazzの進行生成、seedの指定・保存、フレーズごとの連続生成。生成後の編集、再生成のUndo/Redo、生成意図と実際の前後関係の解説。
- 五度圏での比較・転調ブリッジ・連続巡回。発音と同期した調の切替と旧新の分析。
- コード辞典から4モードの聞き流し。日本語の名前とPianoを20分の音声にまとめ、反復再生・ロック画面操作・WAV保存。
- Timeline / Liveの旋律生成、ピアノロール、伴奏と分けた鍵盤表示、旋律の音域・密度・動き・音量・モチーフ・Seedの設定。

### 最初の操作

1. C、G、Am、Fをそのまま押します。最初の操作で音声と音源を準備し、選んだコードが鳴ります。「音声を開始」の事前操作は不要です。初期は記録オン、1イベント4拍、90 BPMです。
2. 「再生」で進行を聴きます。「停止」は予約とvoiceを止めて先頭へ戻します。「一時停止」→「再開」は保持した拍から再発音します。
3. 停止中にイベントを選び、転回を変更します。常に表示する「選択イベントの編集」で長さ・転回・オクターブを調整できます。テンポ・拍数・記録・ループ、配置・A/B試聴・全体移調は進行パネルに常時表示しています。
4. 「コード辞典」で和音を選んで試聴できます。「進行へ追加」でホームに戻ります。
5. 「設定」で音色・音量・言語を選び、JSONの書出し／読込を行います。画面右上の音色名からも設定を開けます。
6. 「生成」の「コードの生成」でPop / Jazzを選び「生成する」を押すと、編集可能な進行に置き換わります。生成そのものは音声開始前でも利用できます。

再生中はパレットが無効です。ループ編集は次の未予約の周回へ反映され、現在の周回は変えません（予約窓120ms）。一時停止中に進行自体を編集した場合は停止状態に戻り、編集済み進行を先頭から再生します。テンポ変更は拍を保って短く再発音します。タブ非表示やAudioContext中断時は一時停止し、復帰後にユーザーが再開します。

調選択は次の和音の文脈を変え、既存の音高とイベントの調は保持します。「進行全体を移調」は全イベントと各調を同じ半音差で移します。転調境界はイベントIDに結び付け、並び順・長さから拍位置を計算します。

### 保存・配置の仕様

新規sessionの配置は「手動（配置を保持）」が初期値。最初のコードは基本形から始まり、転回・オクターブの変更後は確定MIDIをそのまま再生・保存します。転回変更は現在の音域を引き継ぎ、オクターブ上下は和音全体を12半音移します（MIDI 36〜96）。編集対象以外の実音は変えません。Root / Smoothへの変更は全体に適用し、手動へ戻すとその配置を保持。A/B試聴は保存した配置を書き換えません。既存sessionの設定と実音は読込時に保持します。

`src/music` は楽理・分析・配置の純粋関数、`src/state` は履歴とsession検証、`src/audio` はTone adapterと注入可能な時計のscheduler、UIは同じイベントのnotesから表示します。実音の構成音は省略・重複しません。

sessionは `schemaVersion: 4`、設定と安定ID付きイベント（Chord、調、duration、bass制約、policy、確定MIDI notes、任意の生成意図・転調意図）、調の切替イベント（eventId、beat、Key、切替意図）、生成時の設定・seed・フレーズ番号・編集済みフラグを保持します。JSONは5MB・256和音イベント、40–200 BPM、手動設定は0.25–16拍（Live記録は0より大きい実測拍数を保持）、音高とbass・生成意図の整合性を検査します。未編集の生成結果はseedから再現した内容とも照合します。無効／未知schemaは変更を加えず拒否します。400msのdebounce保存が失敗しても演奏と書出しを続けられます。

既存のschemaVersion 1 / 2 / 3は確定MIDI・音色・設定を保持して4へ移行します。旧データでは旋律をオフにして移行します。音色フィールドがなければPianoを補います。localStorageは `chordscape.session.v4` を優先し、なければ旧 `chordscape.session.v3` / `chordscape.session.v2` / `chordscape.session.v1` を移行して利用します。旧保存データは削除しません。

Smoothはオンラインでは直前配置から選び、進行への適用とA/Bでは動的計画法で選びます。冒頭は中央寄りの基本形、同点は固定順序。声部の挿入／削除、移動・跳躍、bass、低域密集、共通MIDI保持、ループ末尾→先頭を評価します。手動bass制約は全モードで優先します。これは定義したコスト内での最適化で、聴感上の唯一の正解ではありません。

### P2の進行生成

入力は調、Pop / Jazz、4 / 8 / 16小節、2 / 4 / 8拍ごとの和音変更、三和音／七の和音、調外和音の確率、終止／ループ、配置、32-bit seedです。Popは短い定番型、Jazzはii–V–I・ターンアラウンドを使い、前のフレーズ末尾からの機能の移行に重みを付けます。終止は主和音、ループは冒頭の主和音へつながるIVまたはV（JazzはV）で終えます。I–V–vi–IVもそのままループできます。調外0%の短調では自然短音階のvを保持します。

調外の確率は候補位置で置換を検討する確率です。解決先を持つsecondary dominantや同主調からの借用を選び、全体に占める調外和音の割合を厳密には指定しません。無限に抽選せず8候補までで既知のパターンへfallbackし、その旨を表示します。4小節・8拍間隔では2和音しかなく、調外和音の挿入余地がないことを表示します。

**C major / Jazz / 4小節 / 4拍間隔 / 七の和音 / 調外100% / ループ / Seed 42**で **CM7 → A7 → Dm7 → G7** を生成できます。表示は **IM7 → V7/ii → ii7 → V7**。A7の解決候補に対してDm7が実際に続く場合だけ、その関係を説明します。並べ替え後は現在の並びを再分析し、保存された生成時の意図とは別に表示します。

`src/music/generation.ts` はDOM・時計・音声に依存しない純粋な生成関数です。generator version 1、Mulberry32、seed、設定、フレーズ番号が同じならChord・意図・ID・voicing・notesは同じです。PlayやJSON読込で乱数を引き直しません。移調などで編集した後は「生成後に編集済み」とし、元の生成条件も残します。

「連続生成を開始」は最初と次のフレーズを確定してから再生します。audio clockへの予約では準備済みフレーズを参照し、その次を予約callbackの外で作ります。現在のフレーズを先に書き換えません。Pause / Resumeやテンポ変更で予約を作り直してもフレーズ番号を保ちます。Stop・音色変更・進行編集で連続生成を終了します。

連続生成は現在のフレーズをtimelineと保存データに保持し、過去のフレーズを無制限には蓄積しません。自動切替はUndo履歴を増やさず、開始前の進行へ戻せます。好きなフレーズで一時停止／停止してJSONへ保存できます。準備に失敗した場合は通知し、準備済みの範囲で終了します。

### P3の五度圏・転調

「五度圏」はSVGの外側に長調、内側に平行短調を表示します。12スロットの異名同音表記はシャープ系／フラット系で切り替えられます。現在調は●、比較する調は上線でも識別できます。Tab / Enter / Spaceのほか、左右矢印で隣、上下矢印で外周／内周を選べます。隣接は調号の近さであり、唯一の転調距離や推奨順序ではありません。

- 調のクリックは比較のみ。「この調を選ぶ」で次のパレットの調を変更します。既存のコード・確定音高・文脈は保持します。
- 共有音はpitch classを比較し、異なる綴りは両方を表示します。共通和音は根音だけでなくqualityと全構成音を比較します。C / Gの共通三和音はC・Em・G・Am、七の和音はCM7・Em7・Am7です。
- 「転調して進む」は進行末尾の調から、進行が空ならパレットの調から提案します。C→GならC → Am → D7 → G。末尾へ追加する場合、出発調の主和音は重ねずAmから接続します。新調のiiやIVを優先して共通和音を選び、続く属七→主和音を作ります。短調の属七は導音を含みます。共通和音のない組合せは直接転調と明示します。
- 提案・再生・イベント選択で旧調／新調の分析を併記します。Amはvi / ii、D7はV7/V / V7、GはV / I。「新調での終止を続ける」で新調のIV（短調はiv）→V7→I/iを追加できます。これはアプリの採用する解釈で、D7→Gだけなら一時的主音化とも聴けます。
- 「ブリッジを試聴」は提案だけを一時再生し、保存した調や進行を変えません。「進行に追加」はUndo可能な編集です。追加時点ではパレットの調を変えず、新調の主和音の発音開始で切り替えます。
- 再生時は音声clockが示すイベントの調を表示・維持します。Stop後は最後に到達した調を保持し、再生し直すと冒頭の調から始めます。Pause / Resume、テンポ変更、ループでも音と同じsnapshotを使います。先読み予約は画面を先に切り替えません。
- 「五度圏を巡る」はパレットの調から時計回り／反時計回りの12区間と帰着を一括生成し、通常のタイムラインとしてループ再生します。C→G→D→A…→Cを繰り返し、進行と調の切替を保存・編集・移調できます。開始は進行を置き換えますがUndoで戻せます。

調の切替一覧はタイムラインから開けます。各和音が保持する調が変わる位置をKeyEventとして保存し、長さ・並べ替え・削除の編集で同時に再計算します。和音を移動するとその和音の調も移動するため、調の往復が増える場合があります。Undo/Redoで境界ごと復元します。JSON読込は調の切替位置・参照先・文脈とコード列の一致も検査します。全体移調では転調意図の旧調／新調を含め同じ半音差で移します。

楽理の確認元: [Open Music Theory: Extended Tonicization and Modulation](https://viva.pressbooks.pub/openmusictheory/chapter/extended-tonicization-and-modulation-to-closely-related-keys/)。

### P4の旋律生成

「生成」ページの「旋律の生成」で設定します。入力済みまたは生成済みの進行がある場合だけ操作できます。初期状態は旋律オフです。「旋律を鳴らす」をオンにし、Timeline / Liveのどちらで演奏するかを選びます。旋律の音色はSoft synth、音量は伴奏とは別に調整できます。master音量は両方に適用します。

**Timeline**：進行がある状態で旋律をオンにすると、確定した音符列を付けます。「旋律を再生成」は伴奏のコード、転回、確定音高、長さを変更せず、旋律Seedを1進めて生成します。Undoで元の旋律へ戻せます。Play / Pause / Resume / Stop、ループ、テンポ変更は伴奏と旋律を同じaudio clockで処理します。Playのたびに乱数を引き直しません。P2の連続生成では次の和音列と旋律を事前準備し、P3の巡回では各コードが持つ調に沿います。

- 初期音域はMIDI 60–84。48–96の間で最低1オクターブを指定できます。伴奏の上を優先し、範囲内に該当する和声音がなければ指定音域を優先します。
- 4/4を前提に、和音の開始と強拍では和声音を使います。弱拍ではその調の音や、実際の次の和声音へ向かう半音のアプローチを許容します。A7ならC♯のように、元の調にない和音構成音も候補にします。
- 密度に応じて2拍・1.5拍・1拍・半拍を混ぜた音符と休符を使います。0%でも最も疎なパターンを演奏し、無音にする操作は旋律オフ／音量0です。同音の連続を抑え、activityで輪郭の幅と動きを増やし、大きな跳躍の後は逆方向を優先します。
- 新しいモチーフは8拍のリズム・輪郭。前半の上昇／下降と後半の応答、末尾の長めの音を組み合わせます。保持オンなら再生成時もモチーフSeedを維持し、音の選び方を変えます。保持オフでは再生成時にモチーフも更新します。旋律generator version 2、旋律Seed、モチーフSeed、設定、進行が同じなら同じ結果です。旧version 1の生成と保存済み音符は保持し、再生成または密度・動き・音域・Seedの変更で新方式へ切り替えます。
- ピアノロールは16拍単位で現在位置を表示し、停止中はタイムラインの和音選択でその位置を表示します。和声音／音階内の非和声音／半音階的な音／休符を色と記号で区別し、詳細リストに音名・拍・分類を表示します。鍵盤は伴奏を●（bassは◆）、旋律を▲で区別します。
- 経過音は実際の前後の和声音を同方向に1–2半音ずつ結ぶ場合に表示します。休符や離れた音では付けません。次の和音へのアプローチも、実際の次の和声音への隣接した解決を確認して表示します。

**Live**：「Liveで演奏」からホームへ戻り、パレットのコードを押して開始します。現在の和音とモチーフから8拍の旋律を生成して反復し、まだ押されていない将来の和音は予測しません。新しいコードの旋律の最初はその和声音です。

- Immediateは現在のaudio clockで適用し、古い未発音の旋律を取り消します。発音中の伴奏・旋律は18ms以内でreleaseし、新しい音へ移ります。
- Next beatは次の整数拍に適用します。境界前の最後の選択を採用し、予定コードと適用拍を表示します。既に120msの先読み範囲で予約した候補でも、上書き時に取り消して置き換えます。
- Recordオンなら実際に適用されたコードを進行の末尾に記録します。選択拍と適用拍を区別し、次の切替・Pause・Stop時に実際の継続拍数を確定します。短いImmediateの区間も四分音符などへ量子化しません。長い区間は最大16拍ごとのイベントに分けます。旋律も当該区間の確定フレーズを切り出し、記録後に別の旋律を生成し直しません。
- Recordオン／オフの変更は停止中に行います。Live中のUndoや進行編集は先に停止します。「再生」または「Timelineで演奏」へ切り替える場合もLiveを停止し、2つのtransportを重ねません。タブ非表示・音声context中断は一時停止します。
- 密度・音域・activity・Seed・旋律オン／オフの変更は停止して反映します。音量は演奏を続けながら変更できます。

schemaVersion 4は設定に旋律version・2つのSeed、各和音に音符の相対beat・duration・MIDI・綴り・分類・解釈、Live記録に適用拍／選択拍を保持します。JSONでは最大128音符／和音、32768音符／session、音域48–96、時刻・音名・分類・解釈の整合性を検査します。伴奏を編集すると旋律オンでは同じ設定から再計算し、オフでは古い旋律を破棄します。全体移調は確定旋律も移し、上限／下限に収まらない場合はオクターブを折り返します。変換後のラベルは再分析します。

表記の確認元: [Open Music Theory: Embellishing Tones](https://viva.pressbooks.pub/openmusictheory/chapter/embellishing-tones/)。

### 拡張和音の表記

Cadd9はC–E–G–D、C9はC–E–G–B♭–D。すべての構成音を省略・重複せず発音し、9thを最低音にする配置にも対応します。6 / m6 / add9 / 9 / M9 / m9は古典的転回数字を付けず和音の種類を保ち、付加6度を含むローマ数字は `I(add6)` のように区別します。実際の最低音はslash名・bass表示・鍵盤で確認できます。

表記の確認元: [Open Music Theory: Chord Symbols](https://viva.pressbooks.pub/openmusictheory/chapter/chord-symbols/)、[Tonicization](https://viva.pressbooks.pub/openmusictheory/chapter/tonicization/)。

### 音色・サンプル

Electric pianoは減衰するFM音源、Padは緩やかな立ち上がりの倍音合成、Soft synthは控えめな倍音合成です。発音ごとの軽量なWeb Audio voiceをToneの時計で予約し、35 Hzのhigh-pass、gain envelope、limiterを通します。Stopは発音前の予約を取り消し、発音中は18msで減衰させます。音色を変更すると演奏を停止します。

PianoはAlexander Holm作 **Salamander Grand Piano / CC BY 3.0**の17サンプル（C2–C6、約1.25 MB）を同梱しています。音声開始後、初めて使うときだけアプリのサブパスから読み込み、外部CDNには接続しません。読込失敗時はElectric pianoに戻して再試行を表示します。出典、変更の有無、原文の著作者表記、ライセンス全文、ファイルのSHA-256は [同梱音源の帰属表示](public/samples/salamander/ATTRIBUTION.md) にまとめています。

### P5の聞き流し

コード辞典の「聞き流し」から入ります。選択中の根音と調を初期値に、4モードを選べます。

- 根音固定：対象のコード種をランダムに選択。
- 調の感覚：調内7和音の名前と度数。開始時と12和音ごとに調と主和音を確認。
- 完全ランダム：12 pitch classesと対象のコード種を独立に抽選。同音の綴り違いを別枠にせず、直前と同じ和音も許可。
- 調内・音だけ：調内7和音をランダム再生。音声の読み上げも主和音の割込みもなし。

「名前→和音」「和音→名前→同じ和音」、2 / 3 / 4 / 6秒の和音、0.5 / 1 / 2 / 3秒の間隔、転回あり／なしを選べます。セットは既定20分（5 / 10分も選択可能）。「セットを作る」で新しいSeedを発行し、完成後に「再生」を押します。「セットを繰り返す」をオフにすれば、セット末尾で自然終了します。繰り返しは同じ並びを再生します。

日本語の短い名前クリップとPianoを端末内で事前に合成し、22,050 Hz / mono PCM16の1本のWAVとしてネイティブのaudio要素で再生します。20分で約50.5 MiB。短い和音ごとのOfflineAudioContextと最大12個のキャッシュを使い、20分のfloat音声バッファを作りません。セット末尾で名前や和音を切らず、残りは無音にします。背景でWeb Speech APIやJavaScriptの予約タイマーを動かし続ける方式ではありません。

再生・Pause・Stop・前後の和音へ移動、ネイティブのシーク、対応ブラウザのMedia Session操作を利用できます。画面非表示では聞き流しを停止せず、復帰時はaudio要素のcurrentTimeから字幕・コード・鍵盤を更新。通常の演奏との同時再生は行わず、別sceneへ移動すると停止・音声URLを解放します。Stopは作成中の処理も取り消し、遅れて再生を始めません。

設定とSeedは `chordscape.listen.v1` に独立保存し、進行JSONを変更しません。生成済みWAVはメモリ内のみで、再読込後は再作成が必要です。「音声を保存」で端末へ保存できます。WAVのRIFF INFOに両音源の著作者・ライセンスを埋め込みます。

名前音声は **VOICEVOX Nemo 女声1（ノーマル）**。コード名を一続きで生成したMP3と、調・度数・転回形の案内を同梱しています。選択したモードで使う音声だけを取得・展開します。[出典・利用条件・変更内容](public/speech/ja/ATTRIBUTION.md) とSHA-256付きmanifestを保持し、画面と書出しWAVにもVOICEVOX Nemoのクレジットを表示します。日本語音声のみで、英語UIでもその旨を表示します。

再生成には公式 **VOICEVOX Nemo Engine 0.24.0**、Python 3、ffmpegを使用します。エンジンをローカルのポート50131で起動し、`node scripts/generate-listen-speech.mjs` を実行します。別ポートは `NEMO_URL=http://127.0.0.1:ポート番号` で指定できます。同じフレーズ・ハッシュの既存ファイルは再利用します。これらは開発時だけ必要で、Webアプリは音声モデルや外部の生成サービスを必要としません。

画面ロック中の長時間再生、イヤホンのリモコン、通話割込みからの復帰はiPhone / Android実機での確認が必要です。Chromiumのモバイルエミュレーションだけで実機対応を保証するものではありません。

### 実装外と手動確認

聞き流しのquiz、英語音声・声の切替、画面オフ中の無限新規生成、旋律の五線譜表示は未実装です。追加style（Classical-ish / City Pop / Lo-fi / Film）、tritone substitution、和音の省略・重複、非構成音bass、独立bassパート、通常の進行／旋律の音声書出し、オフライン起動・ホーム画面へのインストール機能も提供していません。

Playwrightは実際のWeb Audioの出力波形とStop後の無音を検査します。聴感を確認したとは扱いません。Chrome / Firefox / Safari・iOS実機での聴感、音量差、連打時のclickや低域の濁りは手動確認事項です。実施した検証は [VALIDATION.md](docs/VALIDATION.md) に記載します。
